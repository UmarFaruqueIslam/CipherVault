# CipherVault

CipherVault is an educational cryptographic text-protection
application developed with Python.

## Project Goals

- Implement authenticated symmetric encryption.
- Explore password-based key derivation.
- Implement public-key hybrid encryption.
- Demonstrate secure cryptographic key management.
- Test confidentiality, integrity and invalid-input handling.

## Planned Cryptographic Design

- AES-256-GCM for authenticated symmetric encryption.
- Scrypt for password-based key derivation.
- RSA-OAEP for hybrid encryption.
- Python cryptography library for cryptographic operations.

## Technology Stack

- Python 3.12+
- cryptography
- pytest
- Ruff
- Git

## Project Status

Under development.

The cryptographic features are planned and have not yet
been implemented or independently security-tested.

## Security Notice

CipherVault is an educational project, not a production-ready
or independently audited security product.

Do not use it to protect real confidential information.
